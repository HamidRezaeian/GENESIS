# Substrate Comparison Protocol

## Context

After Exp 99 formally falsified SNN-on-RAM as AGI substrate, we must pivot to 
new substrate hypotheses while preserving scientific rigor.

## Protocol

Compare 5 substrate candidates under identical Rule 18/20 controls:

1. **SNN-on-RAM** (historical baseline, artifact analysis only)
2. **Reservoir + NLMS readout** (Exp 103b baseline)
3. **Recurrent/world-model agent** (Dreamer-style latent imagination)
4. **Small transformer** (proven sequence learner, diagnostic only)
5. **Hybrid: transformer core + sparse event-driven memory**

## Evaluation Criteria (Rule 18 gates)

- A: C(t) ≥ 25% improvement in 5M ticks
- B: Learning > matched ablation
- C: C/footprint non-decreasing
- D: Efficiency per Rule 22

## Next Steps

1. Implement baseline for each substrate (1-2 sessions each)
2. Run controlled comparison (same tasks, same ablations, same cost accounting)
3. Report results honestly
4. Pivot to best-performing substrate

## Timeline

- Substrate baselines: 5-10 sessions
- Comparison runs: 2-3 sessions
- Total: ~15 sessions
